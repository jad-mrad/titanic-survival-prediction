# 🚢 Titanic Survival Prediction

Machine learning model to predict Titanic passenger survival using Random Forest.

## 📊 Results
- **Model:** Random Forest Classifier
- **Accuracy:** 81.01%
- **Dataset:** 891 passengers

## 🔍 What I did
1. Loaded and explored the Titanic dataset
2. Cleaned missing data (Age, Cabin, Embarked)
3. Encoded text columns to numbers
4. Split data 80% training / 20% testing
5. Trained Random Forest model
6. Evaluated accuracy and visualized feature importance

## 📈 Key Finding
Fare, Sex and Age were the most important survival factors.
Rich women had the highest chance of survival.
